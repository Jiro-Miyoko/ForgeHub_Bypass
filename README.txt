===============================
Instructions:

Default Hotkeys (Set your keyboard to US if you encounter issues) :
- Cbuf: Right Control + / (press this hotkey in the external console window)
- Noclip: Right Control + N
- God Mode: Right Control + M
- ZM Mode: Right Control + Z (only press this while you're in Local Multiplayer server browser menu)

To set a different keybind for each hotkeys, modify the "virtual key codes" values in _profile.ini. The decimal values for each keyboard keys can be found in many places on the internet (search query: virtual key codes).
===============================

Campaign and Multiplayer (only with bots) are fully playable offline with everything unlocked (weapons, operators, customizations, etc). However LAN is currently not possible at the moment, only local play with bots for now (so don't bother asking about LAN).

How to start MWZ (Zombies):
- Enter Local Play server browser menu, BUT DON'T CLICK ON "CREATE LOCAL GAME" button yet!!!
- Press the ZM Mode hotkey (default: Right Control + Z) on your keyboard until the frontend background changes red
- Create a lobby like usual by clicking on "CREATE LOCAL GAME", then you can setup the map and everything to start the match
- Often times you'll likely to spawn under the map, so be sure to toggle noclip as soon as you spawn in order to get back up

Steam notes:
You can change language by editing steam_settings/configs.user.ini but make sure that you have installed the appropriate language files first.

Side notes:
- Campaign missions can be unlocked all at once by enabling 'UnlockAllMissions' in sp23/_profile.ini
- If you're stuck on "Launching..." screen after starting the game, simply press Esc.
- MWZ offline is very unstable and a bit buggy, especially on big maps like Urzikstan.
